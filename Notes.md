## MESSAGES
Messages are the fundamental unit of context for models in langchain. They represents the input and output of models.

Messages are content that contains:
- Role: identify the message type (e.g system message, user message)
- Content: Actual content of the message (like text, image, video, audio)
- Metadata: information about the input data such as messsage IDs, usage tokens

**TYPES OF MESSAGES**
- **HUMAN MESSAGES:** Represents the user inputs and interactions with model
- **SYSTEM MESSAGES:** How to behave and provide the context for intererction
- **AI MESSAGES:** Response generated by the model, including text content, tool call, meta data
- **TOOL MESSAGES:** Represented the output of tool call
